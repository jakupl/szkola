## kNN 
Kropka bliżej czerwonych jest czerwona a bliżej niebieskich jest niebieska Jak dziala:

1. Wybierz k
2. Zmierz odległosci
3. Znajdz sąsiadow
4. Policz głosy kNN jest bardzo czułe na szum i sie nie uczy.

Scikit podstawowe: Fit, Predict, fit and predict

Nigdy nie używamy całych danych do trenowania modelu Test nigdy nie używamy do poprawienia modelu


Przykładowy algorytm KNN
```
punkty = [
    (1, 2, "A"),
    (5, 7, "A"),
    (2, 5, "B"), 
    (8, 2, "B"), 
    (5, 7, "C")]


def knn(nowy_X, nowy_Y):
    naj_etykieta = None
    naj_dist = None

    for x, y, etykieta in punkty:
        d = (x - nowy_X) ** 2 + (y - nowy_Y) ** 2

        if naj_dist is None or d < naj_dist:
            naj_dist = d
            naj_etykieta = etykieta

    print(f"pkt nalezy do: {naj_etykieta}")


knn(4, 2)
```
